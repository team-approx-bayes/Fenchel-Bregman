\begin{abstract}
Multi-sample reasoning generates several candidate solutions and selects among them at inference time.
Reasoning models use training objectives defined for a single solver execution, although deployment evaluates a candidate pool under a fixed budget.
We place a regularized posterior over solver parameters, using each posterior sample as one candidate solver.
For a prescribed pool size $K$ and reasoning depth, we minimize a differentiable surrogate of the probability that all $K$ candidates fail.
An unbiased stochastic estimate of this finite-$K$ surrogate requires $K$ solver executions per update.
To address this, we derive an exact Fenchel representation of the surrogate whose primal update uses one posterior draw given a per-problem dual state.
We also track this state with a closed-form Bregman update and one running failure estimate per problem.
Together, this optimizes the finite-$K$ surrogate using one posterior draw per update.
Across challenging reasoning benchmarks, we validate finite-$K$ posterior learning improves multi-sample performance.
\end{abstract}
